# Has Unresolved

A small note demonstrating the **Unresolved** bottom-panel tab.

The link below points to a file that does not exist in the demo
workspace:

[[never-created-yet]]

It will render with the unresolved style (color differs from the resolved
[[index]] link above) and the bottom panel's Unresolved tab will list it
under this file's name.

To "fix" it: create a new note named `never-created-yet.md` from the file
tree's right-click menu. The unresolved entry should clear once the
backlink index rebuilds.
