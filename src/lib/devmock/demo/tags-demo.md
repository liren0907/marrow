# Tags Demo

Marrow indexes `#tag` markers across the workspace. Open the **Tags**
panel (sidebar activity bar) to see what's been picked up.

This file uses #project #idea and #demo in the body. It also has an
explicit cluster: #marrow/devmock #marrow/phase-1.

## Why tag indexing?

Quick categorical filtering without forcing folder structure on yourself.
Multi-word topics use kebab-case: #local-first #note-taking.
